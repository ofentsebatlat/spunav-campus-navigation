# 🧭 SPU Campus Navigation (Spunav)

> **Sol Plaatje University Interactive Campus Navigation & Building Directory**  
> **Author:** Ofentse Batlang

---

## 📌 About The Project
Spunav is an interactive campus navigation and venue locator system designed for students, faculty, and campus visitors at Sol Plaatje University (SPU).

## 🛠️ Built With
- Python & Django
- HTML5, CSS3, JavaScript
- SQLite / PostgreSQL

## 🚀 Setup & Run
```bash
python -m venv venv
.\venv\Scripts\activate
python manage.py migrate
python manage.py runserver
```
